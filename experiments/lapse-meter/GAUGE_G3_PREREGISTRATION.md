# Gauge G3: does invariant parameter pressure predict perturbation sensitivity?

**Pre-registered 2026-10-28 before G3 trained-model runs.** Independent of the experiment-number series. Prior work: the component W * dL/dW is connection sensitivity from SNIP (Lee et al., ICLR 2019); invariance under ReLU positive diagonal rescaling is established. This study evaluates numerical predictive calibration, not originality of the identity.

## Prediction
For `P_l = sqrt(sum((W_l * grad_W_l)^2) + sum((b_l * grad_b_l)^2))` and independent Rademacher signs `xi`, the first-order loss change from perturbing only layer l by `W_l -> W_l * exp(eps*xi_W)`, `b_l -> b_l * exp(eps*xi_b)` is
`Delta L = eps * [sum(W_l*grad_W_l*xi_W) + sum(b_l*grad_b_l*xi_b)] + O(eps^2)`.
Over independent random sign directions, the standard deviation of this *linearized* response is exactly `eps*P_l`, and the finite-perturbation deviation should shrink with eps. Positive neuronwise ReLU gauge rescalings commute with elementwise multiplicative perturbations, so the same perturbation produces the same output function, and thus the same finite loss change in the gauge-transformed network.

## Locked design
- Seed 4 and 5 networks not used in G1/G2. Bundled digits, width64, plain ReLU depth8 and residual ReLU depth24; train 500 SGD steps, lr .05, batch64; probe the same first 256 training examples as G1/G2.
- Four layer positions per network: input projection (0), middle hidden (floor((depth-1)/2)), last hidden (depth-1), output (depth); 64 independent Rademacher signs for each layer, generated by a seed-dependent NumPy generator.
- Perturb each layer's original parameters with `exp(0.001*xi)`; compare actual loss change to the linearized predicted change based on its unperturbed batch gradients. For the same directions, repeat the perturbation after the G2 neuronwise diagonal gauge. Report every layer, seed, and architecture, no exclusions.
- Primary test: absolute difference of paired gauge loss changes <1e-9 (each direction), correlation of actual-vs-linearized changes >0.98 (each 64-direction cell), RMS approximation error / RMS linear prediction <0.1, and empirical SD(actual change) / (eps*P) between 0.65 and 1.35 in every cell. If P=0 or the ratio undefined, count that cell untestable and report it.
- Independent stress-test at eps=0.01 with the **same** directions, reported exploratory only. Compare RMS linearization error with eps=.001 but do not claim guaranteed improvement or make it part of pass/fail.
- Failure to pass is a genuine failed prediction. Retain all cells; no cherry-picking. A/P do not claim predict SGD or downstream generalization.
